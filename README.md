# Evidence Screenshots

Add a small number of screenshots that support the investigation narrative.

Suggested evidence:
1. A Splunk search showing relevant PowerShell or process events.
2. An event detail view showing fields you relied on.
3. A view supporting the network-share investigation.
4. Evidence of archive creation.
5. Evidence showing the `curl.exe` command and destination.

Before uploading:
- Remove credentials, tokens, private URLs, and unrelated personal information.
- Make sure each screenshot is readable and has enough context.
- Add a caption explaining what it demonstrates.
- Do not present a command as proof of success unless evidence confirms success.
- Do not upload challenge answer keys or restricted materials.
